# Rohan Fossé

Enseignant et responsable pédagogique en informatique au CESI de Montpellier.

J'écris **[Page vive](https://pagevive.fr)**, un manuel en ligne gratuit d'informatique et de mathématiques pour élèves ingénieurs et débutants. Le code Python, les requêtes SQL et les figures s'y exécutent dans la page, sans compte ni installation.

Quelques parcours : [Algorithmique](https://pagevive.fr/algorithmique) · [Python](https://pagevive.fr/python) · [Bases de données](https://pagevive.fr/bases-de-donnees) · [Réseau](https://pagevive.fr/reseau) · [Graphes](https://pagevive.fr/graphes) · [Recherche opérationnelle](https://pagevive.fr/recherche-operationnelle)

Domaines : recherche opérationnelle, théorie des graphes, satisfiabilité (SAT).
